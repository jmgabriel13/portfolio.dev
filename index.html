AI Engineering Workflow Kit

A practical workflow kit for using Codex and Claude Code without letting AI sessions become vague, expensive, or hard to review.

The problem

AI coding sessions can lose context, over-generate documentation, ignore architecture rules, or skip review gates. That creates output that looks fast but is hard to trust.

The approach

Keep instructions short and task-specific: `AGENTS.md` for global behavior, reusable skills for repeated work, and chained workflows for plan, build, test, review, and document cycles.

The result

More predictable AI output, smaller context payloads, clearer handoffs, and a workflow that still keeps a human engineer responsible for architecture, correctness, and risk.
