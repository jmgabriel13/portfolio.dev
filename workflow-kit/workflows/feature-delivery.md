# Workflow: Feature Delivery

This workflow chains small AI-assisted tasks from idea to review.

1. **Understand**
   Read the request, docs, current code, and constraints.

2. **Plan**
   Use `skills/plan-feature.md` to produce the smallest viable implementation plan.

3. **Implement**
   Use `skills/implement-change.md` to make scoped edits.

4. **Validate**
   Run targeted tests, build checks, linting, or manual browser checks.

5. **Review**
   Use `skills/review-change.md` to find risks before handoff.

6. **Document**
   Update README, usage notes, or changelog only when behavior or setup changed.
