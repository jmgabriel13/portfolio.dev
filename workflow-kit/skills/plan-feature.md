# Skill: Plan Feature

Use this when a request needs implementation planning.

## Inputs

- User goal
- Relevant docs and code paths
- Known constraints

## Steps

1. Identify the user-facing outcome.
2. Inspect existing architecture and related code.
3. Define affected layers and files.
4. List edge cases and failure modes.
5. Define validation and acceptance criteria.

## Output

A short plan with scope, approach, tests, and assumptions.
